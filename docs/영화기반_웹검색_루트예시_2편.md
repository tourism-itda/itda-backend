# 웹 검색으로 선정한 영화 루트 예시 2편

작성/경로 확인: 2026-09-16. 이전 세션의 웹 조사와 중단된 테스트를 이어서 완료했다.

## 이번 작업 기준

- 사용자 요청: 사람의 전수 검수 단계를 두지 않고 우선 AI가 웹 검색·근거 판단을 수행한다. 이번에는 Codex가 Claude 역할을 대신해 2편만 예시를 만든다.
- 사람이 검수해야 다음 단계로 진행한다는 기존 문서의 제안은 이번 예시의 전제에서 제외한다.
- 관련성은 출처가 뒷받침하는 범위로 설명한다. 역사 인물과의 연결 또는 인물 전시를 촬영지로 바꿔 부르지 않는다.
- 아래 관계 분류와 코스는 AI가 웹 근거를 조합해 선정한 결과이며, 관광기관이 해당 영화를 위해 공식 선정한 코스라는 뜻은 아니다.
- 운영 DB와 서비스 API는 수정하지 않았다. 키는 파일에 저장하지 않았다.

## 1. 사도 (content_id=315439) — 화성 자동차 코스

제안 제목: 영화 속 비극, 아들이 남긴 추모의 길

| 순서 | 장소 | 분류 | 선정 근거 |
| --- | --- | --- | --- |
| 1 | 화성 융릉과 건릉 | HISTORICAL | 융릉은 사도세자와 혜경궁 홍씨, 건릉은 정조와 효의왕후의 능. 작품의 실존 인물과 직접 연결된다. 능 두 개를 각각 독립 추천지로 늘리지 않고 융건릉 1곳으로 계산한다. |
| 2 | 용주사 | HISTORICAL | 정조가 아버지 사도세자의 명복을 빌기 위해 세운 사찰로 인물의 사후 추모 역사와 연결된다. 영화 사건이 발생한 장소나 촬영지라고 설명하지 않는다. |
| 3 | 동탄호수공원 | GENERAL | 역사 관람 뒤 호숫가 산책으로 마무리할 수 있는 일반 명소. 작품 관련성 없음. |

구성: 작품 관련 2곳 + 일반 1곳.

카카오 자동차 경로 실측:
- 융건릉 → 용주사: 2,169m / 295초 (약 5분).
- 용주사 → 동탄호수공원: 13,182m / 1,467초 (약 24분).
- 합계: 15,351m / 1,762초 (약 29분).

각 두 구간에서 식당·카페 종류별 첫 페이지 15건이 추가 직선 우회거리 3km 타원 조건을 통과했다. 업체는 확정하지 않고 사용자 선택 후보로 남긴다.

근거:
- 융건릉/용주사: https://korean.visitkorea.or.kr/detail/rem_detail.do?cotid=6a58ffae-68ed-42be-abd7-49b285b2bf7e
- 융건릉 인물 설명: https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=180f8e4a-d60c-4998-a3d0-19cc70835fa3
- 동탄호수공원: https://data.visitkorea.or.kr/page/2654624

## 2. 천문: 하늘에 묻는다 (content_id=569267) — 아산 자동차 코스

제안 제목: 장영실의 과학에서 시작하는 아산 하루

| 순서 | 장소 | 분류 | 선정 근거 |
| --- | --- | --- | --- |
| 1 | 장영실과학관 | EXHIBIT | 작품의 주요 인물 장영실과 연결되는 인물·과학 전시 시설. 장영실관이 업적을 전시하고 조선 과학 기술을 소개한다. 아산이 장영실의 고향 또는 영화 촬영지라는 주장은 하지 않는다. |
| 2 | 외암민속마을 | GENERAL | 전통 마을 풍경을 둘러보는 일반 명소. 영화 관련 장소로 분류하지 않는다. |
| 3 | 신정호관광단지 | GENERAL | 물가 산책으로 마무리하는 일반 명소. 영화 관련 장소로 분류하지 않는다. |

구성: 작품 관련 전시 1곳 + 일반 2곳.

각 두 구간에서 식당·카페 종류별 첫 페이지 15건이 추가 직선 우회거리 3km 타원 조건을 통과했다. 사용자 선택 전 특정 업체를 일정에 확정하지 않는다.

## 적용상 구분

- 이 두 예시는 자동차로 검증했다. 같은 조합을 도보 모드에 그대로 노출하지 않는다.
- 시간은 조회 시점의 명소 간 이동 예상값이다. 출발지 이동, 주차, 장소 내부 관람, 식당·카페 경유/체류는 미포함이다.
- 날짜 지정 없는 코스 예시다. 출시 일정 생성 시 방문일 운영시간과 휴관일을 반영해야 한다. 융건릉·장영실과학관의 월요일 휴관 정보가 확인된다.
- 타원 후보는 장소 API의 분류 결과다. 음식점에 베이커리 등이 포함될 수 있어 점심/저녁 슬롯에는 추가 음식점 분류가 필요하다.
- 길찾기 성공만으로 작품 관련성을 판단하지 않는다. 동일 이름의 주유소, 개별 고택, 관리시설이 검색 결과에 섞여 실제 대표 장소와 구별하는 조건을 보강했다.
- 최종 성공 실행은 키워드 6회 + 자동차 길찾기 4회 + 카테고리 8회 = 18회. 중단 전/수정 중의 재실행은 별도이며 하루 총 사용량을 의미하지 않는다.
